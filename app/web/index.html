    TCP/IP (servidor ASCII)

    Clientes conectados: 0

    Protocolo 
    Comandos (terminar con CR o CRLF):
  TRIGGER | T   → ejecuta inspección y responde
  GET           → último resultado
  STATUS        → READY;<camaraOk>;<modo>
  RECIPE <n>    → carga receta n  → RCP;<n>;<nombre>
  RECIPE?       → receta activa
  SAFETY        → SAF;<peligro>;<advertencia>;<personas>;<zona1>;...
  RESET         → reinicia contador
  PING          → PONG
Respuesta CSV:
  RES;<contador>;<1=OK|0=NOK>;<ciclo_ms>;<herr1>;<herr2>...
  (los lectores de código envían el texto leído)
